# Afternoon Practicum – Image Filter + Binary Tree Node Count

## Overview
In this practicum, you will complete two programming tasks inside `student.c`:

1. Apply a **Green-Boost Image Filter** to a 24-bit BMP file.  
2. Count the **number of nodes in an arbitrary (multi-child) tree**.

Only **one file** (`student.c`) should be edited. All other files are provided and must remain unchanged.

Use **make test** to test files locally.
